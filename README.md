# Son Tra Innovation Fest

Website and CMS for the Son Tra Innovation Fest (SIF), Da Nang — **2–3 October**.

The full scope, sitemap, content structure and decision log live in
`Son Tra Innovation Fest.xlsx`. That workbook is the source of truth for *what*
gets built; this repo is *how*.

## Stack

| Layer     | Choice                                     |
| --------- | ------------------------------------------ |
| Frontend  | Next.js 16 (App Router, RSC) + TypeScript  |
| Styling   | Tailwind CSS v4 + shadcn/ui                |
| i18n      | next-intl — EN (default) + VI              |
| CMS       | Strapi 5 (TypeScript)                      |
| Database  | SQLite in dev, PostgreSQL 17 in production |
| Monorepo  | pnpm workspaces + Turborepo                |
| Deploy    | Docker Compose on the client's own server  |

See [docs/tech-stack.md](docs/tech-stack.md) for why, including the one change
from the original proposal: **Strapi cannot use MongoDB** — support was dropped
in Strapi v4, so Postgres replaces MongoDB Atlas.

## Layout

```
apps/
  web/       Next.js frontend — the 9 public pages
  cms/       Strapi 5 admin + REST API
packages/
  shared/    Locales, sitemap definition, Strapi content-type types
infra/       docker-compose.yml for staging/production
docs/        Stack decisions and deployment runbook
```

## Getting started

Requires Node 22 (`nvm use`) and pnpm 11.

```bash
pnpm install
```

Then set up environment files:

```bash
cp apps/web/.env.example apps/web/.env.local
```

`apps/cms/.env` is generated by the Strapi scaffold and already has working
secrets for local development. Run both apps:

```bash
pnpm dev
```

- Frontend — http://localhost:3000 (redirects to `/en`)
- Strapi admin — http://localhost:1337/admin (create the first admin user)

To run just one:

```bash
pnpm dev:web
```

```bash
pnpm dev:cms
```

## Connecting the frontend to the CMS

1. In Strapi admin, go to **Settings → API Tokens** and create a read-only
   token. Put it in `apps/web/.env.local` as `STRAPI_API_TOKEN`.
2. Under **Settings → Webhooks**, add a webhook pointing at
   `http://localhost:3000/api/revalidate` with the header
   `x-revalidate-secret` set to the same value as `REVALIDATE_SECRET` in
   `apps/web/.env.local`. Publishing content then refreshes the static pages
   without a rebuild.

## Commands

| Command          | Does                                       |
| ---------------- | ------------------------------------------ |
| `pnpm dev`       | Run web + cms in watch mode                |
| `pnpm build`     | Build both apps                            |
| `pnpm typecheck` | TypeScript across the workspace            |
| `pnpm lint`      | ESLint on the frontend                     |
| `pnpm format`    | Prettier across the repo                   |

Add shadcn/ui components from `apps/web`:

```bash
pnpm --filter @sif/web dlx shadcn@latest add button card
```
