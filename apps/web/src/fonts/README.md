# Brand webfonts

Drop the licensed `.woff2` files here. Weights are those specified on page 6 of
`SIF Brand Guidelines.pdf`:

```
FSMagistral-Light.woff2        (300)
FSMagistral-Book.woff2         (400)
FSMagistral-Medium.woff2       (500)
FSMagistral-Bold.woff2         (700)
FSMagistral-ExtraBold.woff2    (800)

SVN-Gilroy-Regular.woff2       (400)
SVN-Gilroy-Medium.woff2        (500)
SVN-Gilroy-SemiBold.woff2      (600)
SVN-Gilroy-Bold.woff2          (700)
```

Then follow the numbered steps in `../lib/fonts.ts`. Font files are licensed
assets — confirm the licence covers **web embedding** before committing them; a
desktop/print licence does not.

Until they arrive the site uses Be Vietnam Pro for both roles.
