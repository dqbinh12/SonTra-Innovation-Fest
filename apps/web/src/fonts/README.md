# Brand webfonts

Drop the licensed `.woff2` files here:

```
FSMagistral-Medium.woff2
FSMagistral-Bold.woff2
FSMagistral-ExtraBold.woff2
SVN-Gilroy-Regular.woff2
SVN-Gilroy-Medium.woff2
SVN-Gilroy-SemiBold.woff2
SVN-Gilroy-Bold.woff2
```

Then follow the steps in `../lib/fonts.ts`. Font files are licensed assets —
confirm the licence covers web embedding before committing them.

Until they arrive the site uses Be Vietnam Pro for both roles.
